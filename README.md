### 👨‍💻 Executive Summary

I am a professional **React Native & Mobile Application Engineer** with **4.8+ years of hands-on industry experience** engineering high-performance, robust, and fluid cross-platform apps for **iOS and Android**. 

My core focus lies in native performance optimization, smooth 60 FPS gesture-driven animations, resilient state management, and offline-first mobile architectures. In step with modern technological advancements, I specialize in augmenting mobile applications with **AI capabilities (Claude, MCP, and LLM APIs)**, supported by a solid foundation in backend systems (**ASP.NET Core / .NET** and **Node.js**).

- 📱 **Primary Focus:** High-Impact Cross-Platform Mobile Applications (React Native / Expo).
- ⚡ **Core Strengths:** Deep expertise in React Native architecture, TypeScript, Redux Toolkit, MobX, and native bridging (Kotlin/Android).
- 🤖 **Next-Gen AI Integration:** Leveraging **Claude API**, **Model Context Protocol (MCP)**, and Agentic AI workflows to build intelligent mobile experiences.
- ⚙️ **Full-Stack Proficiency:** Designing RESTful microservices and APIs with **.NET 10, PostgreSQL**, and **Node.js, Express & MongoDB**.
